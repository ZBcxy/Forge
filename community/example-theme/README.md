# Neon Nights

A vibrant neon theme for Forge OS with deep purple backgrounds and cyan/magenta accents.

## Preview
![Preview](preview.png)

## Installation
```bash
cp -r neon-nights ~/.forge/themes/
forge theme set "Neon Nights"
```

## Customization
Edit `theme.json` and change colors to your liking. See [THEME_SPEC.md](../THEME_SPEC.md) for details.
