# Forge OS Community Theme Marketplace

No website required. No account needed. Just create, share, install.

## For Theme Creators

1. Read [THEME_SPEC.md](THEME_SPEC.md)
2. Run `forge-theme create my-theme`
3. Edit `theme.json` with your colors
4. `forge-theme inspect my-theme` (validate)
5. `forge-theme pack my-theme` (creates .forge-theme)
6. Share on GitHub with tag `#forge-os-theme`

## For Users

1. Find a theme online (GitHub, forums, from a friend)
2. `forge-theme install <file/url>`
3. `forge-theme set "Theme Name"`
4. Enjoy your personalized Forge OS
